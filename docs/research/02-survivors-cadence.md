Research 02 — survivors-genre reward cadence
============================================

Source read: [Jboger, The Secret Sauce of Vampire Survivors](https://jboger.substack.com/p/the-secret-sauce-of-vampire-survivors). Read 2026-11-07.

What the genre does
-------------------

- Many small upgrade tiers (eight per weapon, five per passive) so a stat reward lands roughly every 23 seconds
  instead of every few minutes; occasional large spikes; difficulty that catches up afterwards.
- Meta-progression is many tiny permanent boosts bought with carried-over gold; every run leaves something behind.
- Chests have a slot-machine reveal; the first six are scripted generous before the odds drop.
- The game pauses on each choice, which limits attention strain.
- Declined options recur soon, so no single choice is heavy; depth comes from combinations.
- Side objectives (achievements per character, map locations) give goals across repeated content.

Decisions this changed in the design
------------------------------------

1. **Reward schedule target is one landing every 10–30 s** (Pass 2's table), which this article's measured ~23 s cadence
   supports; the colony's cargo arrivals and the run's container opens are the two sources that can hit it.
2. **The first haul of a run is scripted generous**: the first three containers of the first run on any route roll one
   tier up. Expectations are set before the real odds apply, exactly as the scripted chests do.
3. **Haul manifests unroll item by item with a tier stinger** — the chest animation, applied to the Stash intake.
4. **Many small tiers over few big ones**: Runner skills in 10 steps, structures in 3 visual tiers each, Authority in
   single laws, city tiers in 4 — never one large unlock that gates an hour.
5. **Pause is free in the colony and partial in runs** (0.2× for 3 s then stop on the rig screen): the article's
   friction point, kept where attention would otherwise wear the player out.
6. **Side objectives live in the Codex** (Scrapdex, Strainbook, Memorial, sets) so repeated routes stay goal-bearing.
